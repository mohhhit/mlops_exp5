1. AIM & OBJECTIVES

Aim: To design, build, test, and deploy a production-grade REST API using FastAPI that serves a Machine Learning model trained on the atmospheric pollutant dataset from Experiment 04.

Objectives:

  • Integrate the preprocessed and feature-engineered Air Quality dataset from Experiment 04.
  • Train a RandomForestRegressor model predicting continuous US AQI and EPA air quality classifications.
  • Serialize and manage versioned model artifacts (aqi_model.pkl and model_metadata.json).
  • Implement production REST endpoints (GET /, GET /health, GET /model-info, POST /predict, POST /predict-batch).
  • Enforce schema integrity and boundary validation using Pydantic models.
  • Provide automatic OpenAPI 3.0 documentation via interactive Swagger UI (/docs).
  • Validate service performance and prediction fidelity with automated testing suites.

2. SOFTWARE & ENVIRONMENT SPECIFICATIONS

  • Runtime: Python 3.11.9

  • Machine Learning: Scikit-Learn 1.7.2

5. REST API ENDPOINTS & SCHEMAS

Method Endpoint Description Expected Status
GET / Root metadata, API version, and route manifest 200 OK
GET /health Liveliness probe for container orchestration 200 OK
GET /model-info Model metadata, feature dependencies, and test scores 200 OK
POST /predict Real-time single observation inference 200 OK
POST /predict-batch High-throughput batch inference 200 OK
GET /docs Interactive OpenAPI / Swagger UI interface 200 OK
